# Prompts

Nineteen workflows that walk the assistant through a multi-step task. Each prompt expands into step-by-step instructions that name the tools to call.

| Prompt | Description |
|--------|-------------|
| `find-and-play` | Search for media by name and start playback on a connected client |
| `resume-watching` | Pick up where you left off: in-progress movies, episodes, and audio with resume positions |
| `whats-new` | A personalized viewing guide of recently added media and next episodes to watch |
| `movie-night` | Curated movie suggestions from your library, filtered by genre and rating |
| `music-listen` | Find and play music: search by artist, album, or song, and optionally generate a smart mix |
| `binge-watch` | Check progress on a TV series and queue up the next episodes to watch |
| `fix-subtitles` | Search for and download missing subtitles for a movie or episode |
| `who-is-watching` | Dashboard of all active playback sessions: who's watching what, on which device |
| `troubleshoot` | Diagnose a server issue: check server logs for errors, failed tasks, plugin status, and system status |
| `bulk-metadata-fix` | Find and fix metadata issues across a library: missing overviews, wrong years, missing genres, or re-identify items |
| `subtitle-audit` | Audit a library for missing subtitles and batch-download them |
| `library-report` | Comprehensive library analytics report: stats, codecs, resolutions, unplayed items, recent additions, and duplicates |
| `duplicate-finder` | Find duplicate media items in a library and optionally remove inferior copies |
| `watch-history` | View a user's watch history over a time period: what was played and when |
| `codec-optimize` | Analyze media codecs and optimize transcoding settings to reduce server load |
| `parental-controls` | Set up kid-safe access: create a restricted user account with library access controls, and point to the dashboard for rating limits |
| `server-setup` | Review and optimize server configuration: transcoding, networking, and general settings |
| `library-health` | Comprehensive server health check: status, storage, tasks, plugins, logs, and backups |
| `syncplay-help` | Set up or troubleshoot SyncPlay watch-together groups: client support, user access, media access, network, and server logs |
